# [PRD] Truth & Strike (키보드 워리어 헬퍼)

## 1. 프로젝트 개요 (Concept)
온라인 커뮤니티 및 소셜 미디어에서 발생하는 논쟁 시, 사용자가 압도적인 논리적 우위를 점할 수 있도록 돕는 브라우저 확장 프로그램. 상대방의 허위 사실을 실시간으로 격파하는 **'방어 모드(Shield)'**와, 내 글의 타격감과 커뮤니티 호소력을 극대화하는 **'공격 모드(Sword)'**를 통합 제공한다.

## 2. 핵심 철학 (Core Philosophy)
* **Context is King:** 사용자가 접속 중인 사이트(URL)를 인식하여, 해당 커뮤니티의 최신 트렌드와 암묵적인 룰, 특유의 어투를 완벽하게 모사한다.
* **Fact-based Cynicism:** 모든 방어와 공격은 철저한 '팩트(기사, 위키, 논문 등)'에 기반하되, 표현 방식은 커뮤니티 특유의 냉소와 풍자로 포장한다.

## 3. 상세 기능 요구사항

### 🛡️ [방어 모드] 실시간 팩트 폭격 & 논리 방어막
* **트리거:** 브라우저 텍스트 드래그 후 마우스 우클릭 메뉴 -> 'Truth Check' 실행.
* **URL 인지형 요약:** 현재 접속한 사이트의 말투를 적용하여, 길고 복잡한 팩트 체크 결과를 간결하고 명료한 한 문단으로 요약 출력.
* **객관적 근거 링킹:** 주장의 참/거짓 여부 판별 시, 신뢰할 수 있는 출처(뉴스, 위키백과 등)의 요약과 URL 하이퍼링크를 반드시 포함.
* **고급 토론 전술 및 논리적 오류 탐지:**
  * 상대방의 글에서 '메신저 공격(Ad Hominem)', '논점 일탈(Red Herring)' 등의 논리적 오류를 감지.
  * 오류 발견 시 감정적인 대응을 배제하고, 상대의 얕은 수를 꿰뚫어 보는 듯한 '냉소적 카운터 펀치(대안 문장)'를 사이트 말투로 제안.

### ⚔️ [공격 모드] 개념글 제조기 & 초안 첨삭기
* **트리거:** 텍스트 입력창에서 초안 작성 후 플로팅 버튼 -> 'Strike Enhance' 실행.
* **한 줄 코멘트 (Line-by-line Critique):** 작성된 초안을 분석하여 어떤 문장에 팩트가 부족한지, 어디서 어휘가 밋밋한지 사이트 감성에 맞춰 첨삭.
* **흥행 요소 판별기 (Missing Element Checker):** 
  * '베스트/개념글'로 가기 위한 필수 요소(타격감, 시니컬함, 내로남불 지적, 재미) 중 현재 글에 무엇이 빠졌는지 진단하는 평가 기능.
* **최종 완성본 생성:** 피드백과 누락된 요소를 모두 반영하여, 해당 사이트에서 가장 추천을 많이 받을 법한 완벽한 톤 앤 매너의 글을 재작성하여 제공.

## 4. 기술 아키텍처 및 구현 전략 (Dynamic Context & Agentic Workflow)
단일 프롬프트의 한계를 극복하고 커뮤니티 트렌드를 실시간으로 반영하기 위해 아래의 전략 중 하나 이상을 채택한다.

* **멀티 에이전트 시스템 (Multi-Agent System):**
  * Search & Fact Agent: 검색 API 연동을 통한 팩트 체크 전담.
  * Logic Critique Agent: 논리적 허점, 메신저 공격 등 논리 분석 전담.
  * Style & Vibe Agent: 분석 결과를 바탕으로 현재 URL(예: fmkorea.com)에 맞는 최종 말투와 밈 렌더링.
* **동적 RAG (검색 증강 생성) 기반 톤 앤 매너 주입:**
  * 각 커뮤니티의 실시간 베스트 글을 스크래핑.
  * 실행 시 해당 사이트의 최신 베스트 글 2~3개를 'Few-shot'으로 프롬프트에 주입하여 트렌드 학습 보완.
* **Model Context Protocol (MCP) 활용:**
  * `get_site_vibe()`, `verify_fact_with_links()` 등의 표준화된 도구를 구축하여 클라이언트(익스텐션)와 AI 모델 간 유연한 통신 지원.

## 5. 핵심 평가 프롬프트 구조 (System Prompt: Concept Post Evaluator)
너는 현재 URL {current_url}의 커뮤니티 생태계와 베스트 글의 특징을 완벽히 이해하는 수석 에디터다.
사용자의 초안을 다음 4가지 핵심 요소로 평가하라:
1. **Cynicism (냉소/풍자):** 감정적이지 않고 상대를 비웃듯 여유로운가?
2. **Fact & Link:** 반박 불가능한 팩트나 통계가 포함되었는가?
3. **Punchline:** 글 마지막에 치명적인 한 방(타격감)이 있는가?
4. **Vibe Check:** 이 커뮤니티에서 쓰는 어휘와 문장 구조를 준수했는가?

각 항목의 충족 여부를 점검하고, 부족한 점을 지적한 뒤, 모든 요소를 완벽하게 채운 [최종 개념글]을 작성하라.
